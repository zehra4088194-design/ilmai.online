# Provider logos

Put the official logo of every AI company here. File name = provider key (the text before the "/" in the
model id, without any leading "~"). Supported formats: .svg (best), .png, .webp. Square images work best.

    anthropic.svg    openai.svg      google.svg     deepseek.svg
    perplexity.svg   moonshotai.svg  meta-llama.svg mistralai.svg
    qwen.svg         x-ai.svg        z-ai.svg       cohere.svg
    amazon.svg       microsoft.svg   nvidia.svg     minimax.svg

Missing files are fine: the app shows the provider's initials instead.
