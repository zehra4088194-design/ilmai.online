# TEST STUDIO — SEPARATE QUESTION PAPER, ANSWER KEY & TEACHER COPY PDF SYSTEM

## 1. THREE DISTINCT DOCUMENT TYPES

Every generated test must support three independent export options.

### A. Student Question Paper PDF

This is the normal examination paper.

It must contain:

- Test title.
- Subject and topic, if provided.
- Class/grade, if provided.
- Examination date field.
- Student name field.
- Roll number field.
- Time duration.
- Total marks.
- General instructions.
- All MCQs.
- All short questions.

**STRICT RULE: NEVER INCLUDE CORRECT ANSWERS, ANSWER INDICATORS, EXPLANATIONS OR MARKING SCHEMES IN THE STUDENT QUESTION PAPER.**

MCQ options must appear without identifying which option is correct.

The student question paper must be generated from a sanitized question-only data structure, not from the complete internal test object.

### B. Separate Answer Key PDF

Provide a dedicated Answer Key PDF.

It must contain:

**MCQ Answer Key**
- Question number.
- Correct option letter.
- Correct option text.

Example:

| Question | Correct option | Answer |
|---|---|---|
| 1 | B | Photosynthesis |
| 2 | D | Chlorophyll |

**Short Question Answer Key**
- Question number.
- Suggested model answer.
- Important marking points.
- Marks allocated.

**Long Question Answer Key**
- Question number.
- Detailed suggested answer.
- Important headings and key concepts.
- Expected diagrams or equations where appropriate.
- Stepwise marking distribution.
- Total allocated marks.

The answer key should be accurate, organized and useful for teachers.

For source-based tests, answers must be grounded in the uploaded source material.

Clearly identify any answer that cannot be confidently derived from the supplied material.

Do not fabricate answer keys.

### C. Complete Teacher Copy PDF

**Complete Teacher Copy**

This document combines:

1. Full question paper.
2. Correct answers for all MCQs.
3. Short-question model answers.
4. Long-question model answers.
5. Marking scheme.
6. Marks distribution.
7. Relevant explanations where requested.

Clearly distinguish question-paper pages from answer-key pages using section headings.

`TEACHER COPY — CONTAINS ANSWERS`

- Teacher-copy endpoint requires the appropriate authorization.
